# Empty and Lumina Cores

Make an Empty Core using glass and an **uncharged raw** Lumite Shard. Surround it with four **Infused** Lumite Shards to make a Lumina Core.

<Recipe id="automatons:empty_magica_core" />
<Recipe id="automatons:magica_core" />

The four infused shards already contain 100 paid Lumina. Crafting the core does not charge you again.
Partially charged shards cannot substitute for uncharged ingredients. A core is a crafting component, distinct from the [Automaton Torso](../items/components.md).

Use cores for the body, home Pedestal, Wand and Totem recipes. Current progression does not use amethyst or craftable upgrades.
