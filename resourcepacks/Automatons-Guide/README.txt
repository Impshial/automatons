Automatons Handbook (Minecraft 1.20.1 / GuideME 20.1.15)

Keep this folder unpacked in your Minecraft instance's resourcepacks folder.
Enable "Automatons-Guide" in Options > Resource Packs.

Edit the .md files in assets/automatons/guides/automatons/handbook/ with a
text editor. Start with index.md. Save as UTF-8, press F3+T in Minecraft to
reload resources, then reopen the handbook. No JAR rebuild is needed.

Keep the YAML between the opening --- lines when editing page text.
Images and preview structures are under that handbook folder's assets/.
The book item, live recipes and rendering code still come from the mod.

The Automatons installer preserves edited or deliberately deleted pages.
It adds new defaults and updates only files unchanged since its last install.
Custom files are left alone. Back up this whole folder to save your edits.
