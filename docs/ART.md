# Art and model maintenance
The native worker cuboids are described in `art/lumberton-model.json`, generated by `tools/author_worker_rig.py` with outfits in `tools/worker_outfits.py`. The 256×256 atlas uses one texel per model unit and non-overlapping UV rectangles.

Ordinary bodies are 26 model units tall; the separate armored body is 40. Runtime collisions are 0.7×1.625 and 1.4×2.5 blocks. Native renderers provide thirteen appearances, held equipment, expressive eyes, fishing posture/chair and depleted pose.

Dead Plant and Dead Crop have static cutout textures and cross models. Living sources keep their ordinary appearance until exhaustion. Lumite, shard, Machine, Tank, Collector and Infuser artwork retains its existing native pipeline.

Run `tools/validate_assets.py` for texture sizes, geometry, face density and UV overlap. Dedicated Machine and Infuser validators check their assets. Image publication uses atomic replacement for files open in Windows previews.

`tools/instance_smoke.py --isolated --worksite-review` captures a disposable client review. `tools/import_expansion.py` validates the ten supplied native layouts against manifests and imports block states, metadata, empty containers, display costs and bills.
