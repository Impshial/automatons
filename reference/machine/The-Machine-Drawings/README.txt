THE MACHINE: ASSEMBLY AND CRAFTED PARTS

Base assembly: 3 wide x 4 long x 2 tall, 24 occupied block positions.
Read rows from front to rear; left/right are viewed facing forward from the rear.

BOTTOM LAYER
Row 1: Frame | Frame | Frame
Row 2: Track Block | Frame | Track Block
Row 3: Track Block | Frame | Track Block
Row 4: Track Block | Frame | Track Block

TOP LAYER
Row 1: Frame | Attachment Mount | Frame
Row 2: Cargo Compartment | Operator Station | Cargo Compartment
Row 3: Cargo Compartment | Tank | Cargo Compartment
Row 4: Frame | Lumina Engine | Frame

TOTALS
6 Track Blocks, 10 Frames, 4 Cargo Compartments, 1 Attachment Mount,
1 Operator Station, 1 Tank, 1 Lumina Engine.

Activate the complete base with the Automaton Wand. The Blade Attachment and
Bore Attachment are fitted separately at the front mount, only while The Machine
is at rest. They are not additional blocks inside the 24-position base pattern.
The Bore is a 3-wide x 3-high bank of nine drills. The cab sits lower behind it.

The Tank is the same glass Tank used in the collector. Its recipe is eight glass
surrounding one Empty Core. Four Cargo Compartments provide 108 storage slots.

The component PNGs are individual concept illustrations, not texture atlases or
ready-to-import Blockbench models. Native 16x16 in-game textures still need authoring.
The diagrams are generated from the exact row data and verify all 24 positions.
The individual component artwork was made with built-in image generation.
